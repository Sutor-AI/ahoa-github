# Armadale Townhomes Owners Association — Document Repository

Governance documents, board-meeting materials, and owner-facing web pages for the
Armadale Townhomes Owners Association (AHOA), Hood River, Oregon.

## Structure

- `governing-docs/` — recorded originals and the amendment / review workstreams
  - `00-recorded-original-docs/` — recorded Bylaws and Declaration as filed
  - `00-recorded-originals-cleaned/` — cleaned transcriptions of the recorded docs
  - `02-marc-geller-review/` — package provided to attorney Marc Geller for review
  - `03-owner-vote-changes/` — changes requiring an owner vote
  - `10-house-rules/` — association house rules
- `board-meetings/` — per-meeting materials
- `projects/` — association projects
- `website-owners/` — owner-facing web documents

Mobile-friendly `index.html` pages are generated by `Generate-Indexes_v*.ps1`
(in the workspace root) and published via GitHub Pages.
